# Geometry Dash Clone

A recreation of the game Geometry Dash, built using C++ and the SFML library.

## About The Project

This project focuses on replicating the core mechanics, physics, and fast-paced gameplay of the original Geometry Dash game. It is developed entirely in C++ utilizing the Simple and Fast Multimedia Library (SFML).

## Controls

* **Spacebar**: Jump

## Prerequisites and Setup

The project is configured to be developed and run using Visual Studio Code (VS Code). To build and run this game, you will need:

* Visual Studio Code
* A standard C++ compiler (e.g., GCC/MinGW)
* The SFML library installed and correctly linked in your environment
